# My Everything

Een statische verjaardagssite met foto's en video's. `index.html` opent de site.

Deze site wordt met GitHub Pages als openbare website gepubliceerd. Iedereen met de link kan de site en de bestanden in `images/` en `videos/` bekijken en delen. Plaats hier alleen media voor die openbaar gedeeld mogen worden.

De uploadknoppen bewaren nieuwe bestanden alleen in de browser van de bezoeker; ze uploaden geen bestanden naar de website.
